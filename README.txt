SYLLABUS-BASED NEWS WEBSITE PRACTICAL

Files: index.html and style.css
1. Open this folder in VS Code.
2. Open index.html and choose Open with Live Server.
3. This example uses topics present in the uploaded lab manual: HTML page structure, headings, paragraphs, semantic elements, lists for navigation, hyperlinks, image, audio, video and YouTube iframe, plus basic CSS.
4. Internet is needed for the sample image and YouTube iframe.
5. To play local audio/video, put sample-audio.mp3 and sample-video.mp4 in this folder.
